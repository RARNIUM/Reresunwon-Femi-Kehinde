## TC-001 – Verify if Product added to cart are checked out

*Test Scenario:*
Verify that a registered user can check out their product.

*Precondition:*
User is on the Add to Cart page.

*Test Data:*
None

*Test Steps:*

1. Open the SauceDemo website.
2. Click on Product wanted.
3. Click on ADD to CART.
4. Click ON THE CHECKOUT BUTTON.

*Expected Result:*
The user should be taken to the "Checkout: Your Information" page to input user details.

*Actual Result:*
The user is taken to the "Checkout: Your Information" page to input user details.

*Status:* PASS
